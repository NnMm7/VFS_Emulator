# Эмулятор командной оболочки ОС (Вариант №15)
Разработать эмулятор для языка оболочки ОС. Необходимо сделать работу 
эмулятора как можно более похожей на работу в командной строке UNIX-
подобной ОС.

## Этап 1. REPL
Цель: создать минимальный прототип. Большинство функций в нем пока 
представляют собой заглушки, но диалог с пользователем уже поддерживается.

### Реализованные требования
1. Реализовано в форме графического интерфейся(GUI)
2. Заголовок окна содержит имя VFS
3. Парсер с обработкой кавычек — используется shlex.split(), который
   корректно разбирает аргументы в кавычках. Незакрытая кавычка - сообщение об ошибке «незакрытая кавычка в строке».
4. Сообщения об ошибках - обрабатываются:
   - неизвестная команда
   - неверные аргументы команды
   - незакрытая кавычка в строке.
5. Команды-заглушки ls и cd - выводят своё имя и аргументы.
6. Команда exit - завершает работу эмулятора.

## Этап 2. Конфигурация
Цель: сделать эмулятор настраиваемым, то есть поддержать ввод параметров 
пользователя в приложение. Организовать для этого этапа отладочный вывод всех 
заданных параметров при запуске эмулятора.

### Реализованные требования
1. Параметры командной строки:
   - --vfs <путь> - путь к физическому расположению VFS.
   - --script <путь> - путь к стартовому скрипту.
2. Стартовый скрипт:
   - команды выполняются последовательно;
   - ошибочные строки пропускаются (эмулятор продолжает работу);
   - комментарии (строки, начинающиеся с `#`) игнорируются;
   - на экране отображается и ввод, и вывод - имитация диалога с пользователем.
3. Сообщения об ошибках во время исполнения скрипта - если скрипт не удалось
   открыть или какая-то команда не выполнилась, выводится сообщение.
4. Скрипты реальной ОС для тестирования - приложены файлы run_tests.bat, демонстрирующие запуск
   эмулятора со всеми поддерживаемыми параметрами.

## Этап 3. VFS
Цель: подключить виртуальную файловую систему (VFS).

### Реализованные требования
1. Все операции в памяти - после загрузки VFS из директории на диске
   дальнейшая работа ведётся только с объектами в памяти. Диск больше не трогается.
2. Источник VFS - директория на диске - путь передаётся через --vfs.
   Имя VFS формируется из имени директории.
3. Обработка ошибок загрузки VFS:
   - директория не найдена;
   - путь не является директорией;
   - ошибка чтения содержимого директории.
4. Несколько VFS для тестирования - в папке vfs/ приложены три директории:
   - vfs_minimal/ - минимальная (один файл);
   - vfs_many/ - несколько файлов и подпапок;
   - vfs_deep/ - не менее 3 уровней вложенности.
5. Стартовый скрипт для тестирования всех команд - файл test_full.sh
   содержит примеры всех команд и обработки ошибок.
